# 数据字典与业务口径

## 交易主键

订单号、客户和产品共同构成唯一键。月份统一到月初，用于月度汇总。

## 金额字段

| 字段 | 含义 |
| --- | --- |
| list_revenue | 未扣除任何减项的标价收入 |
| discount | 商业折扣 |
| returns | 退货对应的收入冲减 |
| product_cost | 产品直接成本 |
| fulfillment_cost | 配送、交付等履约成本 |
| service_cost | 售后、支持等客户服务成本 |

净收入等于标价收入减折扣及退货；毛利等于净收入减产品成本；贡献利润等于毛利减履约成本及服务成本。

## 客户组合指标

收入占比用于计算最大客户占比和 HHI。HHI 等于各客户收入占比平方之和，范围为 0 至 1；本项目只把它作为集中度描述，不使用真实监管阈值。

高收入低利润标签表示客户收入排名前二但贡献利润率低于 15%。阈值是演示规则，不是企业通用标准。

## 敏感性边界

情景变化率分别作用于净收入、产品成本、履约成本和服务成本。结果是条件模拟，不是因果推断、统计预测或业绩承诺。
