# 项目三实施计划

## 阶段一 数据契约与合成数据

- 定义客户、产品、订单、退货和服务成本数据表。
- 固定净收入、毛利和贡献利润口径。
- 生成可重复的正常数据和异常测试样本。

## 阶段二 盈利能力计算与勾稽

- 按客户、产品、月份计算净收入、毛利和贡献利润。
- 建立交易明细到客户及产品汇总的数量和金额勾稽。
- 识别高收入低利润、负贡献和交叉补贴现象。

## 阶段三 客户组合与敏感性分析

- 建立贡献利润分层、Pareto 分析、Top N 占比和 HHI。
- 分析价格、产品成本、履约成本和服务成本变化。
- 形成管理建议，但明确区分模型结果与真实业务结论。

## 阶段四 管理报告与一键 Demo

- 输出管理摘要、客户盈利、产品盈利、利润瀑布、集中度、敏感性和数据质量工作表。
- 建立命令行一键运行入口和公开 README。

## 阶段五 验收与求职材料

- 运行自动化测试并复核报告。
- 将项目三写入累计更新版简历。
- 生成项目三 STAR 面试手册。
