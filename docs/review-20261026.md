# 共享费用和阈值复核

运行 `python -m customer_profitability.allocation`。新增独立的50,000货币单位模拟共享费用池，分别按净收入和订单数分配；原产品、履约、服务成本保持直接归属，不重复分配。每种方案分配总额相同。分配后指标不是完整净利润，分摊费用也不等于退出客户即可避免的成本。

阈值组为10%/20%、15%/25%、20%/30%。负贡献优先标记；“高收入低利润”要求收入排名前2且贡献率低于低阈值，并不是把所有低于15%的客户都归入该标签。利润排名不因阈值变化而改变。合成案例中客户甲和戊标签变化，另三位稳定。不能由模拟推导真实收益或客户反应。

实施效果记录模板：方案____ 开始日____ 观察期____ 对照组____ 价格/数量/组合____ 直接成本____ 共同费用及驱动____ 交付投诉____ 回款____ 外部变化____ 结果及局限____。当前无企业实施数据。
