# 客户与产品盈利能力分析模型

这是作品集项目三，面向财务 BP、FP&A 与商业分析场景。项目将使用完全合成的数据，把销售收入逐层拆解为毛利和客户贡献利润，识别高收入低利润客户、产品组合变化、客户集中度与价格敏感性，并输出可复现的 Excel 管理报告。

> 当前状态：项目已完成。合成数据、贡献利润分析、客户集中度、敏感性、一键 Excel 报告和自动化测试均已通过验收。

## 业务问题

- 哪些客户和产品真正创造贡献利润，而不只是创造收入？
- 折扣、退货、产品成本、履约成本和服务成本分别侵蚀了多少利润？
- 是否存在高收入低利润或负贡献客户？
- 收入和利润是否过度集中于少数客户？
- 调整价格、成本或服务投入后，客户盈利能力如何变化？

## 核心口径

- 净收入 = 标价收入 − 折扣 − 退货
- 毛利 = 净收入 − 产品成本
- 客户贡献利润 = 毛利 − 履约成本 − 服务成本
- 贡献利润率 = 客户贡献利润 ÷ 净收入
- 客户集中度使用 Top N 占比和 HHI 指标展示

## 计划交付

- 完全脱敏且可重复的客户、产品和交易合成数据
- 输入校验与收入成本勾稽
- 客户及产品盈利能力分析
- 客户分层、集中度、Pareto 与交叉补贴识别
- 价格、成本和服务投入敏感性分析
- 一键运行 Demo 与 Excel 管理报告
- 自动化测试、公开文档、累计版简历和 STAR 面试手册

## 已实现

- 生成 2026 年 12 个月、5 个虚构客户、4 个虚构产品的 240 条交易记录；
- 校验必要字段、空值、无效月份、重复业务键、负数以及折扣与退货越界；
- 计算标价收入、净收入、毛利、贡献利润和贡献利润率；
- 按客户、产品和月份汇总并保证各层级与交易明细勾稽；
- 计算客户收入排名、利润排名、Top 1 收入占比和收入 HHI；
- 识别高收入低利润客户，并公开 15% 的演示标签阈值；
- 输出降价承压、基准和提价优化三种敏感性情景；
- 一键生成合成输入工作簿和包含 8 张工作表的管理报告。

## 运行演示

```powershell
python -m pip install -e .
python -m customer_profitability.demo
```

安装后也可以运行：

```powershell
customer-profitability-demo --output-dir .\my_demo_output
```

演示生成：

- `合成客户盈利输入.xlsx`
- `客户与产品盈利能力管理报告.xlsx`

默认合成案例的净收入为 2,354,375.44 元，贡献利润为 694,557.91 元，贡献利润率为 29.50%，收入 HHI 为 0.2109。客户甲收入排名第一，但贡献利润率只有 11.24%，因此被标记为“高收入低利润”。

详细口径见 [数据字典与业务口径](docs/data-dictionary.md)。

## 业务边界

- 客户、产品、金额、折扣、退货和成本全部为合成数据；
- 履约成本和服务成本采用演示分配规则，不代表真实作业成本法；
- 15% 标签阈值只用于演示，不能直接作为真实客户去留标准；
- 敏感性分析展示假设变化，不表示预测准确率或因果关系。

## 数据安全

公开仓库只使用程序生成的虚构客户、产品、价格、成本和交易数据，不引入任何真实公司或个人信息。
