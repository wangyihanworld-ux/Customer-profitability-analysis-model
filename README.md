# 客户与产品盈利能力分析模型

这是作品集项目三，面向财务 BP、FP&A 与商业分析场景。项目将使用完全合成的数据，把销售收入逐层拆解为毛利和客户贡献利润，识别高收入低利润客户、产品组合变化、客户集中度与价格敏感性，并输出可复现的 Excel 管理报告。

> 当前状态：项目骨架和业务口径已建立，正在实现合成数据与贡献利润计算模块。

## 业务问题

- 哪些客户和产品真正创造贡献利润，而不只是创造收入？
- 折扣、退货、产品成本、履约成本和服务成本分别侵蚀了多少利润？
- 是否存在高收入低利润或负贡献客户？
- 收入和利润是否过度集中于少数客户？
- 调整价格、成本或服务投入后，客户盈利能力如何变化？

## 核心口径

- 净收入 = 标价收入 − 折扣 − 退货
- 毛利 = 净收入 − 产品成本
- 客户贡献利润 = 毛利 − 履约成本 − 服务成本
- 贡献利润率 = 客户贡献利润 ÷ 净收入
- 客户集中度使用 Top N 占比和 HHI 指标展示

## 计划交付

- 完全脱敏且可重复的客户、产品和交易合成数据
- 输入校验与收入成本勾稽
- 客户及产品盈利能力分析
- 客户分层、集中度、Pareto 与交叉补贴识别
- 价格、成本和服务投入敏感性分析
- 一键运行 Demo 与 Excel 管理报告
- 自动化测试、公开文档、累计版简历和 STAR 面试手册

## 数据安全

公开仓库只使用程序生成的虚构客户、产品、价格、成本和交易数据，不引入任何真实公司或个人信息。
